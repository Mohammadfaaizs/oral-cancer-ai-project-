# OralAI

A full-stack research software prototype for oral-image AI decision support.

### Included
- React/Vite frontend
- Node/Express/MongoDB API
- Python/PyTorch AI service
- Six-class inference
- Grad-CAM
- Clinical demo model
- Admin/user roles
- Patient records
- Prediction history and reports
- Docker Compose stack
- Health checks and smoke tests

### Critical model disclaimer
The bundled model is trained on synthetic demonstration images. It is included only so the software can run end-to-end without external clinical data. It must not be used for diagnosis.

MeMoSA is a separate real dataset of 30,039 oral mucosa images with clinical metadata, available through the MeMoSA Workbench under its access/licensing requirements.
